# E-Commerce Customer Behavior Analytics Dashboard

## Project Overview
This project analyzes e-commerce customer behavior using Python, Machine Learning, and Power BI. It helps understand customer segments, spending patterns, sales forecasts, and customer ratings.

## Objectives
- Analyze customer purchasing behavior.
- Perform data cleaning and exploratory data analysis (EDA).
- Segment customers based on their behavior.
- Predict customer spending and ratings.
- Visualize insights through an interactive Power BI dashboard.

## Technologies Used
- Python
- Pandas
- Machine Learning
- Jupyter Notebook
- Power BI
- CSV Datasets

## Project Features
1. Data Cleaning and Preprocessing
2. Exploratory Data Analysis (EDA)
3. Customer Segmentation
4. Customer Spending Prediction
5. Customer Rating Prediction
6. Sales Forecasting
7. Power BI Dashboard Visualization

## Project Files
- Jupyter notebooks for data analysis and prediction.
- CSV files containing cleaned data and prediction results.
- Power BI dashboard file (`.pbix`).
